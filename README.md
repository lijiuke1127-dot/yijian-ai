## 从自动回复，到持续跟进和自动归档

| 能力 | 具体用途 |
| --- | --- |
| **7×24小时自动回复** | 在电脑、网络、服务和对应客户端持续可用时，按服务时间与回复范围处理咨询 |
| **专属业务 Agent** | 设置工作身份、服务范围、语气和回复长度，配置销售、客服、售后等岗位 |
| **知识库问答** | 使用产品说明、业务规则等资料回答问题，让 AI 了解你的业务 |
| **图片和文件发送** | 将要发送给客户的资料单独配置，按对话需求调用 |
| **主动跟进** | 创建定时任务，向指定会话发送文字、图片和文件，用于回访和客户维护 |
| **会话记忆** | 理解当前会话上下文，让连续沟通更自然 |
| **自动归档与聊天整理** | 在微信聊天整理模块上传记录包，按行业模板或自定义要求自动提取、整理信息，并管理归档记录 |
| **人工随时接手** | 按实际业务选择 Agent 接管或人工辅助，关键情况由人处理 |

## 纯视觉与账号安全

账号安全是一见AI技术路线的重点。一见AI通过视觉识别和系统辅助功能操作真实聊天界面，**不采用破解底层协议的接入方式**。

关于大家关心的“不封号”，应当区分产品采用的接入方式与平台对账号行为的管理：纯视觉不等于平台豁免，账号使用仍需遵守对应平台规则。了解实际运行方式、适用场景和演示，可在文末添加微信咨询。

更多说明：[纯视觉工作方式与账号使用说明](docs/visual-and-account-safety.md)。

## 开始配置你的 AI 员工

1. 从[一见AI官网](https://gw.chantgpt.cn/?utm_source=github&utm_medium=readme&utm_campaign=yijian_ai)下载对应系统版本。
2. 按应用引导完成账号登录和必要权限配置。
3. 在「Agent」中配置身份、服务范围、回复风格与业务知识。
4. 在「平台」中选择 Agent，设置服务时间、名单和回复范围。
5. 先在自己的测试会话中检查回复、资料发送和人工接手，再用于实际业务。

完整步骤见[快速上手](docs/getting-started.md)。软件授权、开通和套餐信息以应用内及咨询时展示为准。
